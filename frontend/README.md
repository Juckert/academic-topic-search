# Веб-интерфейс

React, TypeScript и Vite. Интерфейс содержит проверку темы, фильтры, историю, черновики с подборками найденных работ и настройки профиля.

## Запуск

Требуется Node.js 22.12 или новее из поддерживаемой ветки.

~~~powershell
cd frontend
npm ci --ignore-scripts
npm run dev
~~~

Адрес приложения — http://127.0.0.1:5173.

По умолчанию включён демонстрационный поиск по словам на восьми синтетических записях. Для подключения локального JSON-каталога выполните из папки frontend:

~~~powershell
npm run import-demo -- ../data/topics.json
~~~

Импортёр также принимает HTML-прототип со встроенным каталогом. Записи с метками синтетических опечаток и перефразировок исключаются. Локальный каталог исключён из Git. Сборка в режиме API использует только синтетические демонстрационные примеры.

## Подключение API

Создайте .env.local по образцу .env.example и установите:

~~~dotenv
VITE_SEARCH_MODE=api
VITE_API_BASE_URL=/api/v1
~~~

Перезапустите Vite. Запросы /api направляются на http://127.0.0.1:8000, где должен работать поисковый сервис (`python -m topic_search.api`, см. [LOCAL_RUN](../docs/LOCAL_RUN.md)). Сборку в режиме API вместе с сервисом запускает `scripts/serve.ps1` из корня проекта. Ошибка API отображается в интерфейсе. Настройки VITE_* доступны браузеру и должны содержать только публичную конфигурацию.

[Контракт API](../docs/API_CONTRACT.md) и [OpenAPI](../docs/openapi.json) описывают формат запросов, ответов и ошибок.

История, черновики и подборки сохраняются в IndexedDB для текущего адреса приложения. Очистка данных сайта удаляет записи. Если постоянное хранилище недоступно, интерфейс показывает уведомление и хранит новые изменения до обновления страницы. При открытии прежнего формата хранилища на том же адресе выполняется преобразование записей.

## Проверка и сборка

~~~powershell
npm test
npm run build
npm run preview
~~~

Сборка находится в dist. Для выдачи реальных результатов приложению необходим поисковый API.
